# AI Assistant 
A python-based AI voice assistant that can listen to voice command
respond using speech open websites open youtube searches interact with AI
and an perform a basic Pc controls

# Features
- voice command recognition
- Text-To-speech responces
- AI-powerd chat responces
- open websites desktop apps and pc controls

# Requirments
Before running the project make sure you have :
Python 3.x
A working micrphone
Internet connection
Required Python pakages
An API key for the AI chat Features
